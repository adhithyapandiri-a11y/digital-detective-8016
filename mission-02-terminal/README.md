## 2. Work Completed
### Task 2.1 — Explore basic Terminal operations
| **Operation / Command Name** | **What it does ?** | **What I Observed !** |
| :--- | :--- | :--- |
| Current-directory display 'pwd' | Shows the root path of working directory | Showed absolute path |
| Directory listing 'ls' | Shows all the visible files/folders in working directory | It showed both files and folders |
| Detailed listing 'ls -l' | Shows the permissions ,file size and few others in addition to 'ls' command | Showed most information about the files |
| Change directory 'cd ..' | Moves the working directory to one level up , to parent directory | Takes to the previous folder (one level up)|
| Create directory 'mkdir (name)' | Creates a new directory | Created a new empty directory |
| Create empty file 'touch (name) ' | Creates an empty file of any extension | Creates an empty file of most types |
| Copy file 'cp (src) (dest)' | Copies a file from source location to destined location | Copies file without deleting the original |
| Move / rename file 'mv (src) (dest)' | Moves or renames a file | Can move and rename a file |
| Display file contents 'cat (name)' | Shows all the contents of a file | Shows text written inside a file |
